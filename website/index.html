GOOD QUESTIONS

Things you might
be wondering.

Need a tailored quote or a guided demonstration? Get in touch.

Can BrewPOS work without internet?

Yes, the current Android prototype uses local SQLite for checkout and order history. Automatic cloud sync is planned for the hybrid version and is not yet available.

Can one printer print both slips?

The Android implementation prepares a customer receipt and a separate barista slip sequentially for one Bluetooth Classic ESC/POS printer. Hardware compatibility must be tested.

Is there a lifetime license?

Lifetime activation is device-bound for the purchased version. It does not include unlimited upgrades, support or hardware replacements.

Can I view reports from anywhere?

Not yet. The linked dashboard is a visual demo using example data. Cloud reporting is planned for the hybrid release.
